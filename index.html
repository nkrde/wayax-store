    About this app

    WayaX AI brings in-house stock recommendations, personalised by WayaX AI. This demo build opens with a cinematic WayaX intro and covers a three-step sign-up (name, mobile number and OTP), the WayaX AI and Waya Research home screens, and the side menu with your profile and chats. The app checks this store each time it opens and offers updates as soon as they’re published here.

    How to install

    1. Tap Install and let the download finish.
    2. Open the downloaded file from your notifications or the Files app.
    3. If asked, allow “Install unknown apps” for your browser, then go back.
    4. If Play Protect warns about an unrecognised app, tap More details → Install anyway.
